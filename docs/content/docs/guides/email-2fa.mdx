## Prerequisites

- A mailserver capable of sending emails

## Setup

<Steps>
<Step>
### Configure Environment Variables

In your `.env.local` file, add the following lines:

```ini
EMAIL_HOST=<mailserver>
EMAIL_PORT=<smtp port>
EMAIL_SSL=<true/false>
NOREPLY_EMAIL=noreply@<your domain>
NOREPLY_PASSWORD=<password>
```

Replace `<mailserver>`, `<smtp port>`, `<true/false>`, `<your domain>`, and `<password>` with your mailserver's information.
</Step>
<Step>
### Done!

Yep, it's that easy :)
</Step>
</Steps>
