At the time of writing, LibreCloud is not in the state of perfection, and as such we are
expecting that you have a setup exact to ours. While this will change in the future, we still
suggest that provide all the listed environment variables.

## Primary

These are the environment variables which handle how `librecloud/web` functions.
With these variables, you can disable entire parts of the dashboard, such as registration.

| Environment Variable             | Description                                               | Expected Value                         | Requirement |
|----------------------------------|-----------------------------------------------------------|----------------------------------------|-------------|
| NEXT_PUBLIC_SIGNUP_ENABLED       | Controls if the signup page and APIs are enabled/disabled | `true` (Enabled) or `false` (Disabled) | Required    |
| NEXT_PUBLIC_DONATE_URL           | Changes the universal donation link for buttons/links     | String - `https://...`                 | Optional    |
| NEXT_PUBLIC_SUPPORT_EMAIL        | Email displayed in the "Support" tab of dashboard         | String - `example@example.com`         | Optional    |
| NEXT_PUBLIC_TELEGRAM_CHANNEL_URL | Changes the default Telegram channel link in Support dash | String - `https://t.me/...`            | Optional    |
| NEXT_PUBLIC_TELEGRAM_GROUP_URL   | Changes the default Telegram group link in Support dash   | String - `https://t.me/...`            | Optional    |

## Altcha

Altcha is a privacy-friendly CAPTCHA alternative we use for bot traffic mitigation and anti-spam.
It requires a secret key for generating and verifying challenges. The rest is handled by the API.

| Environment Variable | Description                                               | Example                                | Requirement |
|----------------------|-----------------------------------------------------------|----------------------------------------|-------------|
| ALTCHA_SECRETKEY     | Secret key for generating and verifying Altcha challenges | N/A                                    | Required    |

### Automatic Secret Key Setup

We've included an automatic setup script for your Altcha secret key. It generates and writes a secure token to your `.env` or `.env.local` file. You can execute this script like so:

```bash
bun tools/hmac.ts
```

## Authentik

We use [Auth.js](https://authjs.dev) to provide authentication for users through Authentik.
To do this, you will need to create a new OAuth2 provider in Authentik and put its configuration in your `.env` file.

If you need more help doing this, reference the [Connecting Authentik with LibreCloud](/docs/guides/authentik) guide.

| Environment Variable  | Description                                             | Example                                         | Requirement |
|-----------------------|---------------------------------------------------------|-------------------------------------------------|-------------|
| AUTH_AUTHENTIK_ID     | (Auth.js) OAuth2 Provider - Client ID                   | `UHEkjdUIqi938hUIEijdkWZiudhIUshefIJIo8u3u`     | Required    |
| AUTH_AUTHENTIK_SECRET | (Auth.js) OAuth2 Provider - Client Secret               | [long string]                                   | Required    |
| AUTH_AUTHENTIK_ISSUER | (Auth.js) OAuth2 Provider - OpenID Configuration Issuer | `http://authentik.local/application/o/example/` | Required    |
| AUTHENTIK_API_KEY     | API key for authenticating with Authentik's API         | N/A                                             | Required    |
| AUTHENTIK_API_URL     | Authentik's API endpoint URL                            | `http://authentik.local/api/v3`                 | Required    |

## Email 2FA

For deleting user accounts, two-factor authentication via email is enforced. Thus, you must set your mailserver information:

| Environment Variable | Description                            | Example               | Requirement |
|----------------------|----------------------------------------|-----------------------|-------------|
| EMAIL_HOST           | Hostname of your email server          | `mail.example.com`    | Required    |
| EMAIL_PORT           | The port to use for sending            | `465`                 | Optional    |
| EMAIL_SSL            | Whether SSL should be used for sending | `true` / `false`      | Optional    |
| NOREPLY_EMAIL        | Email account to send from             | `noreply@example.com` | Required    |
| NOREPLY_PASSWORD     | Password for the account given         | Your password         | Required    |

## ownCloud

The ownCloud integration requires an admin or service account credentials for the OCS API.

You must create a service account and enter its login details into your `.env` file to use these features. You can also use an app password instead of a password.

| Environment Variable    | Description                                           | Example                       | Requirement |
|-------------------------|-------------------------------------------------------|-------------------------------|-------------|
| OWNCLOUD_URL            | The URL of your ownCloud instance (no trailing slash) | `https://files.librecloud.cc` | Required    |
| OWNCLOUD_ADMIN_USERNAME | Admin/service account username                        | `service-account`             | Required    |
| OWNCLOUD_ADMIN_PASSWORD | Corresponding password to given admin/service account | Password                      | Required    |

## Forgejo/Gitea

Next, you will need to configure `web` with your Forgejo/Gitea instance.
Create a new access token in your Forgejo/Gitea user settings,
and input the key you receive, as well as the URL of your instance, and the API URL.
You can find a link to the API and its endpoint URL on the footer.

| Environment Variable  | Description                                           | Example                                    | Requirement |
|-----------------------|-------------------------------------------------------|--------------------------------------------|-------------|
| GITEA_API_URL         | Your Forgejo/Gitea instance API endpoint (see footer) | `http://forgejo.local/api/v1`              | Required    |
| GITEA_API_KEY         | Access Token created in user settings                 | `0000000000000000000000000000000000000000` | Required    |
| NEXT_PUBLIC_GITEA_URL | Your Forgejo/Gitea instance URL                       | `http://forgejo.local`                     | Required    |

## mail-connect

mail-connect, another project by LibreCloud, is a bridge from `docker-mailserver` to an API. It talks to the container via a Docker socket, but you will need to tell `web` where to find your mailserver API.

Keep in mind, this endpoint should **NOT** be public, and `web` should be the only authorized user of the API, unless you know what you're doing. There is zero authentication.

| Environment Variable | Description                  | Example                 | Requirement |
|----------------------|------------------------------|-------------------------|-------------|
| MAIL_CONNECT_API_URL | URL of your mail-connect API | `http://localhost:4200` | Required    |

## SearXNG

SearXNG is our search provider of choice for LibreCloud. These options configure the dashboard to use your instance for several services.

Don't be afraid to use LibreCloud Search for your private/public LibreCloud instance. We don't mind!

| Environment Variable    | Description               | Example                        | Requirement |
|-------------------------|---------------------------|--------------------------------|-------------|
| NEXT_PUBLIC_SEARXNG_URL | Your SearXNG instance URL | `https://search.librecloud.cc` | Optional    |
