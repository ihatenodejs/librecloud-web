You can freely modify the LibreCloud documentation on our [repository](https://github.com/ihatenodejs/librecloud-web) in the `docs/content/docs` folder. We encourage contributions of all kinds!

## Editing Guidelines

- Have common sense, please.
- Obviously, this is not the place to rant about your political beliefs or spread hate.
- Test the instructions/docs you write, if possible.
- Yeah, just have common sense

## Generate Docs

You can generate the docs with the following command:

```bash
bun run docs:generate
```

The docs will be served at `http://localhost:3000/docs`, where `localhost:3000` is your domain (unless you're using a development server).
